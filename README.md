# Portfolio - Lincoln Gustavo (Edição Cinematográfica)

Este é o repositório do meu portfólio profissional como Editor de Vídeo Cinematográfico. O site foi projetado para ser uma vitrine de alta conversão, focando em performance, retenção e autoridade visual.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica focada em SEO.
- **CSS3**: Estilização moderna com animações avançadas, Glassmorphism e design responsivo.
- **JavaScript (Vanilla)**: Lógica interativa para carregamento de vídeos, contadores de estatísticas, scroll spy e feedback de formulário.
- **YouTube API**: Integração otimizada com placeholders para carregamento sob demanda (Lazy Loading).

## ✨ Funcionalidades Principais

- **Performance Otimizada**: Vídeos carregam apenas no clique, economizando banda e melhorando o tempo de carregamento inicial.
- **Experiência do Usuário (UX)**:
    - Barra de progresso de leitura.
    - Navegação inteligente (Scroll Spy) que destaca a seção atual no menu.
    - Botão "Voltar ao topo" e integração direta com WhatsApp.
- **Prova Social & Autoridade**: Seção de depoimentos e contadores de estatísticas animados.
- **Acessibilidade**: FAQ estruturado para navegação via teclado e uso de ARIA labels em elementos visuais.
- **Design Cinematográfico**: Tema escuro com gradientes dinâmicos e efeitos de hover "premium".

## 🛠️ Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/portfolio-video-edicao.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador moderno.
